# Meta Building Blocks for Floor Fracture

![Building Blocks entry in the Unity Meta tools, supplied by Wais](./Media/Meta-Building-Blocks.png)

The November 19, 2026 review covered all 68 serialized block definitions in the project's installed SDK 209 packages. This count includes hidden dependencies, deprecated definitions and internal prototypes. The public catalog lists the blocks that players and developers commonly encounter. A Unity Interaction SDK Quick Action or an official sample can also supply a complete implementation. The installed MRUK placement helper and the game’s footprint checks ran in five native synthetic rooms. GameRoom fitted 12 × 2, High-ceiling Room 6 × 9, Furniture-filled Room 4 × 4, Corridor 10 × 3 and L-shape Room 3 × 9. The complete rectangle cleared the recorded obstacles in each room within 1 mm. The separate Mac simulator showed both the Passthrough and Projection layers with a readable Welcome panel. [Room geometry and layer checks](<./Verification/Overnight simulator.json>) · [Mac window](<./Media/Meta simulator Welcome.jpg>)

MRUK can describe a level floor as several anchors. The fitter takes the union of adjoining or overlapping coplanar outlines and checks the resulting rectangle against walls, furniture and interior holes. It uses Unity's existing polygon operations for this step. In a standalone Quest trial, joining two adjacent 2 × 2 m sections doubled the usable glass area to 8 m². A gap, a step or a wall kept the two sections separate. [Measured Quest layouts](<./Verification/Joined floors and canceled wave on Quest.json>)

### Inference Engine for the LLM block

Meta SDK 209 checks for the exact package `com.unity.ai.inference@2.3.0`. The stock release uses two APIs that fail to compile on Unity 6000.6.9f1. This project embeds 2.3.0 under `Packages/com.unity.ai.inference/`, with Unity's corresponding 2.6.1 updates to `Runtime/Core/PluginInterfaces.cs` and `Editor/Visualizer/Editor/ModelAssetOpenHandler.cs`. Package Manager reported the embedded version, Meta's own dependency check returned true, and script compilation completed with zero errors. The optional local Results experiment ran Meta’s UnityInferenceEngineProvider with SmolLM2 on the Mac CPU and GPU. It correctly named one of three real loss types. The shipped game reads the authoritative loss event and keeps the model out of the Android package. The three recorded lines play completely offline. [Trial results](<./Verification/Offline coach experiment.md>) [Unity embedded package workflow](https://docs.unity.com/en-us/engine/6000.0/manual/packages-list/dependencies-lp/upm-embed) · [Unity 6.6 object ID migration](https://docs.unity.com/en-us/engine/6000.6/manual/scripting/get-started/instanceid-to-entityid-migration)

The macOS standalone simulator supplies room anchors and a coarse global mesh. When its live Depth API is unavailable, the Editor uses the installed MRUK Invisible Occluder shader on the above-floor triangles. The physical Quest uses live depth so it can respond when furniture moves. The surrounding brick compares the current and prior Meta soft-depth measurements at the same world point. The matched synthetic head-motion test measured 7.0 mm of edge movement with the revised material and 29.1 mm with the earlier material. [Two-eye comparison](<./Verification/Floor entry visual checks.json>) [Measured simulator result](<./Verification/Brick floor simulator.json>)

Meta’s MCP server supplies the official documentation and current device information. Its Quest tools can also read app logs, capture a headset view and profile a device. Unity’s installed SDK supplies the actual block definitions, assets and scene installer. On this Mac the standalone Meta XR Simulator is installed. The former `com.meta.xr.simulator` 81.0.0 package produced four Editor compile errors with Core 209. Meta moved the Unity controls into Core and directs developers to remove that package. Physical stepping rules out teleport during a round. Multiplayer, avatar retargeting and shared anchors belong to a future shared version. Raw camera access, object recognition, image segmentation and speech input would introduce data pathways outside the current mechanics. Placement uses the saved room, its global mesh, headset tracking and the available environmental raycast provider.

For every new feature, check the installed definition, prefab, relevant Quick Action and official sample first. Record what it delivers, what Floor Fracture still needs, and how the integration was verified. Ask Wais before choosing a new asset or AI provider.
