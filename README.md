# Floor Fracture

A solo mixed-reality survival game for Meta Quest 3. Step off cracking glass before the countdown reaches zero. The connected glass board fits the scanned floor around obstacles. Passthrough shows your real floor outside the panes, and Meta depth lets foreground objects occlude the glass. Real walls and furniture stay in view as neighboring panes open into shafts.

## Open the project

Install Unity `6000.6.10f1` with Android Build Support, the Android SDK and NDK, and OpenJDK. Clone with Git LFS enabled, run `git lfs pull`, and open this directory in Unity Hub. Unity resolves Meta XR `209.0.0` and Unity OpenXR `1.19.0` and Unity OpenXR: Meta `2.7.0` from the package lockfile.

Open `Assets/FloorFracture/Scenes/FloorFracture.unity`. The Android build list points to this scene. The signed ARM64 package is `com.wa003.floorfracture`. Git `3265e4b` is the earlier template-scene packaging baseline. Game source is under `Assets/FloorFracture/`.

## Play

1. Open the game and allow spatial data. A saved floor can arrive after the room opens. The game keeps checking and brings up Welcome when it can fit the glass. **Check again** reloads the saved room. Use **Space Setup** to capture or update the floor and furniture. The game compares rectangular and irregular layouts and keeps the one with more playable glass. Each pane and its 8 cm clearance must fit inside Meta’s mapped floor and clear furniture and confirmed obstructions. Small bumps and gaps in the saved mesh can still hold tiles. Welcome shows the fitted board, which can be a strip of connected panes down to 40 cm across. The gold outline follows the playable edges around obstructions. Use **Play area → Refit saved floor** with a hand ray or fingertip poke to check the current floor again.
2. Press a menu button with a fingertip, point and pinch with a hand, or point and press the controller trigger. Choose **Tutorial** and stand on the glass. When your pane cracks, step onto a clear neighbor. After practicing, choose **Start wave**. **Try the stone (optional)** lets you grab a rock and drop or toss it onto any intact pane.
3. Choose **Start wave**. After **3, 2, 1, GO!**, watch for amber cracks and listen for the crackle from each marked pane. Every required step gives you at least one second. Ordinary waves open at 2.00 seconds on level one, 1.50 on level three and 1.00 from level six. From level six the marked glass can fall together or in rows. Keep stepping as each row cracks. When a gap opens around you, cross one opening to any clear pane within reach. You have at least 1.85 seconds once the gaps open. From level nine you can get two jump waves in a row. The ring underfoot shows your support. Look through an opening to see the level’s trap 80 metres below. Hazards build up as you climb. Fog drifts below knee height from level 2 and partly hides the amber cracks, with patches that settle over single panes from level 3. From level 3 a wave can send sliding panes, and a slider can still be moving when the next wave adds more (up to one per wave at levels 3–5, two at 6–8, three from 9). A slider stops when you land on it. From level 4, sweeping spotlights wash out cracks with bright pools and hum from the lamp’s direction. From level 5, lightning flashes twice overhead and thunder follows from that direction, and patrol panes slide around corners along a path of 3–5 cells. With Reduced motion on, lightning is one soft glow. From level 6 some levels end with a ride instead of Last Tile: every stationary pane breaks, the pane beside you starts to slide, and you step onto it before it slides out of reach.
4. During a fall, a fresh index pinch with either tracked hand, or A or X on a controller, skips ahead to Results. **Settings** includes reduced-motion falls, warning intensity, volume, an optional offline narrator and **Immersive room**, which turns passthrough off and draws your scanned room, furniture and a stone floor with Meta’s Effect Mesh. In mixed reality, Meta’s Real Hands block keeps your own hands visible in front of the menu. Results identifies the actual cause of a loss. **Retry Level N** restarts the level you lost on fresh glass at wave 1 with a new score. **Choose level**, available here and on the main menu, opens every level you have reached. Progress saves on this device as soon as the next level’s Ready screen appears, even if you quit before its first wave. **Start** always begins at Level 1.

## Build and install

In **File → Build Profiles**, select the saved **Meta Quest** profile. It uses Vulkan, ARM64, the project's Mobile URP quality level, Android API 32 minimum and API 34 target. The global scene list contains the playable FloorFracture scene. Choose **Build** or **Build And Run**. For a command-line build on this Mac, run the following from the project directory. Set `FLOOR_FRACTURE_DEV=1` for the development menu and local measurement recording.

```sh
/Applications/Unity/Hub/Editor/6000.6.10f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -quit -quitTimeout 1200 -projectPath "$PWD" \
  -activeBuildProfile "Assets/Settings/Build Profiles/Meta Quest.asset" \
  -executeMethod FloorFracture.Editor.GameProjectSetup.BuildAndroid \
  -logFile "$TMPDIR/FloorFracture-build.log"
```

The default output is `Builds/Quest/FloorFracture.apk`. Use a separate checkout for a clean build. The command allows twenty minutes for Unity to finish any queued work. The batch build closes Meta’s Interaction SDK telemetry session before the Mac Editor exits. [Release verification](<./Docs/Verification/Latest Quest release.json>) · [Unity command-line arguments](https://docs.unity.com/en-us/engine/6000.6/manual/unity-editor/command-line-arguments/editor)

To sideload, enable developer mode on the Quest, authorize USB debugging, and use Android Platform Tools. With one authorized headset connected, run `adb install -r Builds/Quest/FloorFracture.apk`, then open Floor Fracture from Unknown Sources.

The Mac batch test runner closes the Meta Interaction SDK telemetry session at exit. Its two verified runs each returned exit code zero with 67 tests passed. This Editor-only fix is included in the source archive. [Batch test exit](<./Docs/Verification/Mac batch test exit.json>)

On the project Mac, the class build is `Builds/CleanRelease/FloorFracture-1da914c.apk`. The local Git repository for course review is `Builds/Handoff/FloorFracture-CourseReview.git`. Its `course-review` branch includes the game, documents and Git LFS media. Its history starts with the public starter project. The adjacent `FloorFracture-CourseReview.verification.json` identifies the reviewed source ZIP and its SHA-256. A fresh clone can be opened in Unity. The course checkpoint is published on the [`course-review` branch](https://github.com/Wais-A/Floor-Fracture/tree/course-review). Earlier local commits and older APKs contain a Meta editor pairing credential. The current build keeps the local editor configuration on this Mac and packages an empty, disabled assistant configuration. Rotate the earlier credential before sharing any historical copy. ## Reproduce and verify

- **Meta XR Simulator.** Enable the standalone simulator, select a synthetic environment, open `Assets/FloorFracture/Scenes/FloorFracture.unity` in Unity, and enter Play Mode. In the separate **Left eye** viewport, Welcome appears once the room and eye height are ready. The game rechecks a late floor automatically. **Check again** reloads the saved room on demand. The saved desktop profile uses MultiPass on Metal. [Recovery menu in the Mac window](<./Docs/Verification/Room recovery hand menu.jpg>) · [Current Welcome screen](<./Docs/Verification/Fitted room Welcome in the simulator.jpg>) · [Settings on Mac](<./Docs/Media/Settings in the Mac simulator.jpg>) · [Five room fits](<./Docs/Verification/Overnight simulator.json>)
- **Offline Editor fixture.** With the simulator disconnected, enter Play Mode. It loads Meta’s recorded `MeshLivingRoom1` room, including its global mesh. To try another installed recording, assign its JSON asset to **Editor Room Recording** on the scene’s **Room Board Placement** component. The gold perimeter identifies the playable board. With desktop input active, walk with WASD, look with the arrow keys, use Q/E for left/right grip, and click or use the numbered menu choices.
- **Placement diagnostics.** Select **Show / hide placement** directly on **Find a clear floor** in the Editor or development APK. After Welcome, use **Play area → Placement debug**. Green outlines mark accepted panes. Colored contours show measured obstructions and scan gaps. Only accepted panes appear as tiles. **Check again** retries in the game. **Space Setup** opens the Quest system scanner, which controls its own hand pointer. [Legend, scan measurements and recorded-room results](<./Docs/Verification/Observed floor placement.md>)
- **Seeded rounds.** In an Editor or development build choose **Development → Seed 379 · level 1**. On a 4×4 footprint, start in cell 0 (local negative X, negative Z). Follow cells 1, 2, 3, 7, 6 to see Classic, Memory and Last Tile. With the level 3 control, follow the guaranteed stationary neighbors until an ordinary pane starts sliding into a neighboring opening. Move onto it to hold it exactly where you landed. From level six, two panes can move at once where separate lanes fit. Stay over the exposed hole while it is away to test a miss. The automated game replay exercises both outcomes at seed 379.
- **Endings.** Choose **Development → Next ending** until the desired name appears, then **Preview loss**. For the player path, stay on the starting pane through zero. A retail build selects endings from its independent shuffle.
- **Checks.** Use **Tools → Floor Fracture → Run board rule checks** for the deterministic planner and **Verify gameplay in Play Mode** for the fixture, real physics, deadlines and replay flow. Reports appear under `Builds/Verification/`. On Quest use the [playtest sheet](<./Docs/Quest playtest.md>) and [performance guide](<./Docs/Quest performance.md>).
